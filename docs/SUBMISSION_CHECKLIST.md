## Где взять правильный образ

1. Откройте [сборку 42444850648](https://github.com/raastaa/vneurok-max/actions/runs/42444850648).
2. Войдите в GitHub и в разделе Artifacts скачайте **vneurok-max-docker**.
3. Распакуйте ZIP. Внутри нужен файл **vneurok-max-docker.tar.gz**, размер **43 021 594 байта**.
4. Проверьте SHA-256:

```sh
sha256sum vneurok-max-docker.tar.gz
# На macOS: shasum -a 256 vneurok-max-docker.tar.gz
```

Ожидается:

```text
f62db3ae9f809164e8fb4dcabaae9f64a728632c09fa3b654773430c5f4e2f5a
```

Это сумма **tar.gz внутри ZIP**, не самого ZIP. После проверки образ можно загрузить в Docker:

```sh
gunzip -c vneurok-max-docker.tar.gz | docker load
```

Тег: `vneurok-max:a216b3da85545c5604daa5163ecdc9da8d422b59`. Платформа: **Linux amd64**. Команда загрузки не запускает бота и не подключает MAX.
